# WalkMyPlan

Design your floor plan in chat and walk through it in 3D. Turn DWG or PDF plans into 3D, furnish rooms, and see the design as a photorealistic image.

## Use it

1. Install the plugin, then connect WalkMyPlan using Claude's connection and authentication flow.
2. Ask Claude in plain words, for example: "Design a 3-bedroom single-story house with an open kitchen and show it to me in 3D."
3. Claude uses the included skill: it looks first, shows what it plans to change, and asks for your approval before making changes.

## Data

This bundle contains instructions and a reference to the existing remote connector at https://mcp.walkmyplan.com/mcp. Tool requests are handled by WalkMyPlan (https://www.walkmyplan.com/privacy). This bundle contains no separate storage service.
